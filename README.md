## 📝 Project Overview
**Dreamweaver - Hospitals** is a web-based application designed to streamline hospital operations, improve patient-doctor interaction, and manage medical records efficiently. Designed and structured within Adobe Dreamweaver, this project combines a sleek user interface with a robust backend to simulate a real-world healthcare management system.
